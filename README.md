# namba-yasaka

浪速区元町2丁目9番の街区（難波八阪神社のある一画）を歩き、パトカーと消防車で走れるブラウザ用のゲームです。

https://github30.github.io/namba-yasaka/ （WebGPU 対応の Chrome / Edge で開いてください）

描画ライブラリは使わず、WebGPU を直接呼ぶ手書きの WGSL と、外部クレートなしの Rust を WebAssembly にしたコアで動いています。
モデルは Blender で手続き的に作ったもので、写真のテクスチャは使っていません。

| 操作 | キー |
|---|---|
| 視点 | クリックしてマウス（ドラッグでも可） |
| 移動 | W A S D、Shift で走る |
| 一人称 / 三人称 | V |
| 車の乗り降り | E |
| 運転 | W/S アクセル・後退、A/D ハンドル、Space ブレーキ |
| 赤色灯 | L |
| ウインカー | Z / C |
| 飛行カメラ | F（Q/E で上下） |
| 時刻 | T、`[` `]` |
